#  Sales Dashboard — Microsoft Excel

## Overview
An interactive Excel sales dashboard analyzing sales performance 
across product categories, US states, top customers, 
and monthly/yearly trends (2014–2017).

##  Dashboard Preview
![Sales Dashboard](dashboard_preview.png)

##  Key Insights
- **Top Sub-Category:** Phones ($330K) and Chairs ($328K)
- **Technology** shows highest profit growth over 2014–2017
- **Top Customer:** Tamara Chand drives the most profit
- Sales peak in **November (Month 11)** each year

##  Tools & Features Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers (Category, Year filters)
- Conditional Formatting

- Pie, Bar & Area Charts

##  How to Use
1. Download `Sales_Dashboard.xlsx`
2. Open with **Microsoft Excel 2016 or later**
3. Use the **Category** and **Year** slicers to filter data interactively
